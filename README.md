From the repository, you can download updates for the 'custom' directory (custom.zip) and the MAME file (hh_sm510.zip) required for compiling games. Just replace them in the program directory.

LCD-Game Shrinker and Retro Go INSTRUCTION:

These are special versions, modified by me, that run via an EXE file on PC. You can also compile them with a single EXE click. For the MAME file and files in the 'custom' directory, there is no need to recompile the program after making changes. The software includes everything required for compilation, execution, and building games.

To run games on the emulator, either drag the game file onto 'Emulator.exe' or place it in the 'ROMS' directory - the emulator will load the first file alphabetically. The game window can be resized.

CONTROLS: A - SELECT, S - START, T - GAME, G - TIME, X - A, Z - B, B - PAUSE/SET, E - sound on/off, W - reset, Q - exit.
